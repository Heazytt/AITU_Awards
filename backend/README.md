# Backend

Java + Spring Boot. Handles authentication and access control, applications, expert assignments, evaluations, deterministic eligibility checks, and reports.

- src/main/java/ - application source code.
- src/main/resources/ - resources and configuration without secrets.
- src/main/resources/db/migration/ - PostgreSQL migrations.
- src/test/ - tests.

The project configuration, pom.xml, Maven Wrapper, Dockerfile, and run instructions will be added when development starts.
