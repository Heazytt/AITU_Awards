# Документация для команды

Здесь хранится русская документация для внутреннего обсуждения. Основные README и документация в ../docs/ ведутся на английском языке.

- [project-overview.md](project-overview.md) — описание проекта и исходной структуры.
- [services/](services/) — пояснения по backend, frontend и AI-сервису.
- [infrastructure.md](infrastructure.md) — инфраструктура.
- [diagrams/](diagrams/) — русские версии диаграмм.
- requirements/ — требования и рабочие пояснения к ТЗ.
- architecture/ — архитектура и технические решения.
- research/ — литература, сравнение аналогов и записи встреч.
- ux/ — макеты и пользовательские сценарии.
- testing/ — план проверки и результаты тестирования.
- presentation/ — русские черновики презентации.

При изменении диаграмм обновляйте обе языковые версии. Названия файлов и расположение диаграмм совпадают с docs/diagrams/.
