# Backend

Java + Spring Boot. Основная бизнес-логика, авторизация и права доступа, заявки, назначения экспертов, оценки и отчёты.

- src/main/java/ - исходный код.
- src/main/resources/ - ресурсы и конфигурация без секретов.
- src/main/resources/db/migration/ - миграции PostgreSQL.
- src/test/ - тесты.

Инициализация проекта, pom.xml, Maven Wrapper и Dockerfile будут добавлены при начале разработки.
