# AI Service

Python + FastAPI. Анализ загруженных документов и извлечение года достижения с подтверждающим фрагментом.

- app/ - код сервиса.
- tests/ - тесты.

Проверки временных условий выполняются по годам. Основной backend сопоставляет извлечённый год с допустимым пятилетним периодом и подтверждённым периодом работы в AITU.
ИИ не назначает официальные баллы и не выбирает победителей.

pyproject.toml, Dockerfile и инструкция запуска будут добавлены при инициализации сервиса.
