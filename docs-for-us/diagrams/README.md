# Диаграммы на русском

- [Процесс и действия по ролям](bpmn/application-process.mmd) - вход через Microsoft, слои преподавателя, эксперта, администратора и автоматической обработки.
- [Структура базы данных](erd/erd.mmd) - начальная логическая модель данных. Названия таблиц и полей на английском, подписи связей на русском.

Сплошные стрелки на схеме процесса показывают действия и переходы; пунктирные - передачу данных и результаты обработки.
Схема Mermaid flowchart показывает пользовательские действия по ролям и не является формальной моделью BPMN 2.0. Формальные модели можно хранить в формате .bpmn.

Исходники хранятся в .mmd без Markdown-обрамления. Экспортированные SVG/PNG размещайте в exports/. Папки uml/ и context/ подготовлены для следующих диаграмм.

ERD - первоначальная логическая модель, а не готовые миграции. При реализации необходимо обеспечить одну заявку преподавателя на конкурс, согласованность номинации и версии правил с конкурсом и только одну текущую ревизию оценки на назначение эксперта.
Корпоративный идентификатор пользователя связывает запись с Microsoft Entra ID. Пароли Microsoft в базе платформы не хранятся.
