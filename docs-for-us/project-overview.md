# AITU Teaching Excellence Awards

Платформа для подачи заявок преподавателей AITU, проверки подтверждающих документов и экспертного оценивания.

## Структура

- [backend/](../backend/) — Java + Spring Boot.
- [frontend/](../frontend/) — веб-интерфейс; стек определит фронтендер.
- [ai-service/](../ai-service/) — Python-сервис анализа документов.
- [docs/](../docs/) — требования, диаграммы, исследования, UX, тестирование и презентация.
- [infra/](../infra/) — инфраструктурные конфигурации.
- [.github/workflows/](../.github/workflows/) — автоматические сборки и проверки.

База данных: PostgreSQL. Вход: корпоративный Microsoft-аккаунт AITU через Microsoft Entra ID.

## Состояние проекта

Создана начальная структура репозитория. Код приложения и конфигурации запуска пока отсутствуют.
Файлы pom.xml, pyproject.toml, Dockerfile и compose.yaml следует добавить при инициализации сервисов.
Инструкции запуска будут размещены в README соответствующих сервисов.

## Правила хранения файлов

- Секреты и локальные настройки хранить в .env, который исключён из Git.
- В .env.example добавлять только названия переменных и безопасные примеры.
- Реальные документы преподавателей не хранить в репозитории.
- Исходники диаграмм хранить в docs/diagrams/, экспорт для презентации — в docs/diagrams/exports/.
- Файлы .gitkeep сохраняют пустые папки в Git; после добавления содержимого их можно удалить.
