# Documentation

This directory contains English project documentation. Russian versions and team notes belong in [docs-for-us/](../docs-for-us/).

- [diagrams/](diagrams/) - Mermaid diagram sources and exports.
- requirements/ - technical specification and functional and non-functional requirements.
- architecture/ - architecture descriptions and technical decisions.
- research/ - literature review, system comparisons, and consultation findings.
- ux/ - mockups, user scenarios, and Figma links.
- testing/ - verification plans, metrics, and test results.
- presentation/ - slide text and presentation files.
